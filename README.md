# ӘКІМ — симулятор акима Алматы

**Играть:** https://rootvandal.github.io/akim/

3D-копия Алматы на реальных данных: 198 тыс. зданий, 2 800 км улиц, 8 районов, рельеф Заилийского Алатау.
Вы — аким. У вас 100 млн ₸ (на лёгком уровне — 500 млн) и 60 месяцев (один месяц = одни игровые сутки, ~30 секунд; партия на 30–40 минут). Первая миссия — победить пробки:

* индекс пробок по городу за 6 месяцев — не выше **30%**;
* в каждом из 8 районов — не выше **50%**;
* репутация не должна упасть до нуля (иначе — отставка).

Казна пополняется каждый месяц: трансферт растёт с репутацией, налоги — когда пробок меньше; платный въезд, парковка и камеры приносят деньги, но злят жителей.
За выполненную миссию республика выделяет новый бюджет и даёт следующую задачу:
«Зелёная Алматы» (парки в 10 минутах от дома) и «Чистый воздух» (зимний смог).

## Запуск

```bash
python tools/serve.py 8799
```

Откройте http://localhost:8799. Нужен браузер с WebGL2 (Chrome, Edge, Firefox, Safari 16.4+).
При первом запуске — интерактивное обучение (его можно пройти заново в «Помощи»).
Игра сохраняется автоматически в конце каждого месяца (и при закрытии вкладки) в localStorage браузера;
при следующем запуске — «Продолжить». Сложность: лёгкая (500 млн ₸, доход ×1,5), нормальная (100 млн ₸), сложная (60 млн ₸).
Качество графики — кнопка «Графика» (низкое / среднее / высокое) или `?q=low|medium|high`; `?debug` — `window.AKIM` для отладки.

## Что можно делать

| Где | Меры |
| --- | --- |
| Клик по улице | реверсивное движение, односторонка, «зелёная волна», запрет парковки, выделенная полоса (или её отмена), расширение |
| «Развязки» | двухуровневая развязка на перекрёстке главных улиц (стройка 14 мес., пока идёт — хуже) |
| «Время» | начало уроков по районам, рабочий день госслужбы, пары в вузах, гибкий график в бизнесе, удалёнка по пятницам, ночной завоз, платная парковка в центре |
| «Парки» (миссия 2) | новые парки: на пустыре дёшево, частные дома выкупаются, многоэтажки сносить нельзя |
| «Воздух» (миссия 3) | газификация частного сектора по районам, ТЭЦ-2 на газ, электробусы, эко-зона |

У мер есть цена, содержание в месяц и реакция жителей. Изменения работают не сразу: водители
перестраивают маршруты несколько месяцев. Город растёт (~2% жителей в год, машин больше),
поэтому без мер пробки за пять лет вырастут примерно с 62% до 80%, а жители потеряют терпение.

## Как устроена модель

* **Данные.** `tools/fetch_osm.py` и `tools/fetch_buildings.py` качают OpenStreetMap через Overpass API и рельеф (AWS Terrain Tiles, SRTM).
  `tools/build_data.py` строит граф дорог (сжатие узлов степени 2, сильносвязная компонента, ворота на трассах из области),
  здания с этажностью, землепользование, зоны спроса 1,5 × 1,5 км и растр районов. Всё сжато в `data/*.gz` (~7 МБ).
* **Население** районов — официальные данные 2019 года, масштабированные к 2 341,9 тыс. (ноябрь 2025);
  внутри района жители распределены пропорционально жилой площади зданий OSM.
* **Спрос.** 28 типов поездок (дом↔работа отдельно для госслужбы и бизнеса, дом↔школа по районам школ,
  вузы, дела, въезд из области, транзит, такси и доставка). Гравитационная модель (для работы — двусторонняя, Фурнесс).
* **Время суток.** 48 получасовых интервалов: профили выезда зависят от расписания школ, госслужбы, вузов и бизнеса.
* **Маршруты.** Дейкстра от каждой зоны для утра, дня и вечера; каждый месяц — шаг Франка–Вулфа с точным
  линейным поиском (часть водителей переходит на лучшие маршруты, не больше половины за месяц).
* **Задержки** — функция BPR `t = t0 (1 + 0.62 x^4)`; индекс пробок как у TomTom: на сколько дольше поездка, чем по пустому городу.
* **Репутация** — настроение районов тянется к уровню, который задают пробки, плюс затухающие реакции на решения и события.

Калибровка: `tests/calibrate.html` (параметры `capacity`, `demand`, `alpha`, `exp=1` — эффекты мер, `months=120` — 10 лет без вмешательства).
Баланс кампании: `tests/balance.html?s=nothing|full|max` — 60 месяцев реальной модели для трёх стратегий игрока
(без мер миссия не выполняется; агрессивная стратегия выполняет миссию 1 примерно за 12 месяцев).

## Честно об ограничениях

Это игровая модель, а не транспортный прогноз акимата: нет общественного транспорта как сети, нет поворотных задержек
на перекрёстках, жилые улицы не входят в граф маршрутов, этажность большинства зданий оценена по площади.
Цифры откалиброваны так, чтобы стартовые пробки (~55%) и их география были правдоподобными.
